# SCALE Task Review v3

Дата ревизии: 2026-04-09  
Источник: `godot/scripts/game_state.gd` (`_default_tasks()` + фильтры `get_weekly_tasks()`)

## Легенда

- `ОК` — задача уместна для Scale-целей.
- `Показать позже` — логичнее после минимальной зрелости экономики/продукта.
- `Показывать, но блокировать` — можно показывать как цель, но с гейтом по метрикам.
- `Нужен ребаланс` — эффект/стоимость/риск требуют тонкой настройки.

## Важное по текущей логике показа

1. В Scale попадают задачи с `stage: "scale"` и `stage: "all"`.
2. Увольнения показываются только если соответствующая роль уже нанята.
3. `Уволить Друга` — только при `friend_count > 0`.
4. `Срочно: бридж-раунд` — кризисная задача (`crisis_only`), инжектится в пул при кассовом разрыве.
5. До `Startup Fellows` командные задачи скрыты (кроме HR и самой задачи Startup Fellows), но на Scale обычно уже не актуально.
