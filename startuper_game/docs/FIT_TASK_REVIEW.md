# FIT Task Review v1

Дата ревизии: 2026-04-09  
Источник: `godot/scripts/game_state.gd` (`_default_tasks()` + фильтры `get_weekly_tasks()`)

## Легенда

- `ОК` — задача уместна для целей Fit.
- `Показать позже` — лучше показывать после роста ключевых метрик Fit.
- `Показывать, но блокировать` — видно в пуле как цель, но эффекты должны идти после базы.
- `Нужен ребаланс` — эффект/стоимость/риск требуют корректировки.
- `Не участвует` — сейчас не попадает в Fit-пул из-за отсутствия `stage: "fit"` (или `all`).

## Важное по текущей логике

1. В Fit попадают только задачи с `stage: "fit"` или `stage: "all"`.
2. Часть задач ниже в `_default_tasks()` без поля `stage` фактически **не участвует** в генерации.
3. Командные задачи остаются под гейтами:
   - до `Startup Fellows` командные задачи скрыты;
   - найм `CMO/CTO/CFO/COO` возможен только при наличии `HR`.
4. Кризисный `бридж-раунд` может появиться на Fit при кассовом разрыве/низком runway.

## Рекомендуемые правки v1.1

1. Проставить `stage: "fit"` задачам из списка «не участвуют», которые реально должны выпадать на Fit.
2. Для `Нанять фриланс-разработчика` пересмотреть баланс (сейчас может ухудшать техдолг при росте burn).
3. Для `Нанять Друга` в Fit ввести прогрессивную стоимость по количеству друзей.
