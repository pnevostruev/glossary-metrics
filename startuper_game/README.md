# Мамкин Единорог

Папка содержит pre-production материалы для разработки обучающей 2D-игры про технологический стартап.

## Что уже подготовлено

- `docs/GDD_v1.md` - полный game design документ версии 1.
- `docs/PRODUCTION_ALGORITHM.md` - пошаговый алгоритм работ до релиза 1.0.
- `godot/` - стартовый каркас vertical slice на Godot 4.

## Ближайший следующий шаг

Этап `Vertical Slice` уже запущен:

- 12 ходов (1 квартал),
- 20-30 минут на сессию,
- базовая экономика стартапа,
- ключевые обучающие выводы после партии.

## Как запустить

1. Открыть папку `startuper_game/godot` в Godot 4.x.
2. Запустить сцену `res://scenes/main.tscn` (или просто Play).
