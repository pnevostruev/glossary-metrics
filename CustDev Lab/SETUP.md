# Инструкция по настройке парсера CustDev Lab

## Шаг 1: Установка зависимостей

```bash
cd "/Users/pnevostruev/Downloads/Глоссаний метрик/CustDev Lab"
pip3 install -r requirements.txt
```

Или установите вручную:
```bash
pip3 install telethon python-dotenv
```

**Примечание:** На macOS обычно используется `pip3` вместо `pip`. Если `pip3` не работает, попробуйте:
```bash
python3 -m pip install telethon python-dotenv
```

## Шаг 2: Получение API ключей

1. Перейдите на https://my.telegram.org/apps
2. Войдите используя ваш номер телефона (код подтверждения придет в Telegram)
3. Заполните форму для создания приложения:
   - **App title**: CustDev Lab Parser (или любое другое название)
   - **Short name**: custdevlab_parser (или любое другое короткое имя)
   - **Platform**: Desktop
   - **Description**: можно оставить пустым
4. После создания вы получите:
   - **api_id** - число (например: `12345678`)
   - **api_hash** - строка (например: `abcdef1234567890abcdef1234567890`)

## Шаг 3: Настройка credentials

### Вариант 1: Файл .env (рекомендуется)

Создайте файл `.env` в директории проекта:

```bash
cd "CustDev Lab"
cp .env.example .env
```

Откройте `.env` и добавьте ваши ключи:

```
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
```

**⚠ Важно:** Не коммитьте файл `.env` в git! Он уже добавлен в `.gitignore`.

### Вариант 2: Переменные окружения

```bash
export TELEGRAM_API_ID=ваш_api_id
export TELEGRAM_API_HASH=ваш_api_hash
```

## Шаг 4: Проверка доступа

Запустите скрипт проверки:

```bash
python check_telegram_api.py
```

Этот скрипт:
- Проверит наличие API ключей
- Проверит установку библиотеки telethon
- Попытается создать клиент (если ключи найдены)

Если все ок, увидите:
```
✓ Проверка завершена успешно!
  Можете запустить parse_channel.py для парсинга канала
```

## Шаг 5: Парсинг канала

Запустите основной скрипт:

```bash
python parse_channel.py
```

### Первый запуск

При первом запуске потребуется:

1. **Номер телефона** - введите ваш номер с кодом страны
   ```
   Например: +79123456789
   ```

2. **Код подтверждения** - код придет в Telegram
   ```
   Введите код: 12345
   ```

3. **Пароль 2FA** (если установлен)
   ```
   Введите пароль 2FA (если установлен): ваш_пароль
   ```

4. **Количество постов** - введите число или нажмите Enter для всех
   ```
   Количество постов для скачивания (Enter = все доступные): 100
   или просто нажмите Enter для всех
   ```

### Последующие запуски

При следующих запусках аутентификация не потребуется (сохраняется в `custdevlab_session.session`).

## Результат

После успешного парсинга:

- **Посты** будут сохранены в `content/posts/` как отдельные `.md` файлы
- **Архив** будет сохранен в `content/archives/` как `.json` файл

Формат имени файла поста:
```
post_231_универсальные_продукты.md
```

## Решение проблем

### Ошибка: "TELEGRAM_API_ID и TELEGRAM_API_HASH не найдены"

**Решение:**
1. Убедитесь, что создали файл `.env` в директории проекта
2. Проверьте, что ключи указаны правильно
3. Попробуйте установить переменные окружения вручную

### Ошибка: "Библиотека telethon не установлена"

**Решение:**
```bash
pip install telethon
```

### Ошибка: "Канал @custdevlab не найден"

**Решение:**
1. Убедитесь, что вы подписаны на канал @custdevlab
2. Проверьте, что канал публичный или у вас есть доступ
3. Попробуйте указать полное имя: `custdevlab` (без @)

### Ошибка: "SessionPasswordNeededError"

**Решение:**
Введите ваш пароль 2FA, который установлен в настройках Telegram.

### Ошибка: "ApiIdInvalidError"

**Решение:**
1. Проверьте правильность api_id и api_hash
2. Убедитесь, что api_id - это число (без кавычек)
3. Попробуйте создать новое приложение на https://my.telegram.org/apps

## Дополнительные возможности

### Парсинг ограниченного количества постов

```bash
python parse_channel.py
# Когда спросит количество, введите число:
Количество постов для скачивания: 50
```

### Парсинг начиная с определенного ID

Можно модифицировать скрипт, чтобы парсить начиная с определенного сообщения:

```python
posts = await parser.parse_channel(limit=100, offset_id=123456)
```

### Экспорт только JSON

Можно отключить создание отдельных `.md` файлов, оставив только JSON архив.
