# 🚀 Запуск CustDev Lab — Одна команда!

## ⚡ Просто запустите:

```bash
cd "/Users/pnevostruev/Downloads/Глоссаний метрик/CustDev Lab"
python3 run.py
```

**Всё!** Скрипт автоматически сделает:
1. ✓ Проверит и установит зависимости
2. ✓ Проверит API ключи
3. ✓ Поможет их настроить (если нужно)
4. ✓ Запустит парсинг канала

## 📝 Что нужно при первом запуске:

### 1. Получить API ключи (если их ещё нет)

Скрипт спросит вас об API ключах. Чтобы их получить:

1. Откройте: **https://my.telegram.org/apps**
2. Войдите используя номер телефона
3. Создайте приложение:
   - **App title**: CustDev Lab Parser (любое)
   - **Short name**: custdevlab_parser (любое)
   - **Platform**: Desktop
4. Скопируйте **api_id** и **api_hash**

Когда скрипт спросит — вставьте их.

### 2. Аутентификация (при первом парсинге)

Скрипт попросит:
- **Номер телефона**: `+79123456789` (с кодом страны)
- **Код из Telegram**: код придет в сообщении
- **Пароль 2FA**: только если установлен двухфакторная аутентификация

При следующих запусках этого не потребуется!

Если что-то не работает:
1. Убедитесь, что используете `python3` (не `python`)
2. Проверьте, что у вас есть интернет
3. Убедитесь, что вы подписаны на канал @custdevlab
4. См. подробную инструкцию: [SETUP.md](SETUP.md)
