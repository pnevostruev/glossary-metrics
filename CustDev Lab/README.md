# Проект "CustDev Lab"

## 📢 О проекте

**CustDev Lab** — это проект, посвящённый телеграм-каналу [@custdevlab](https://t.me/custdevlab).

## 🔍 Пример контента

### Пост #231: "Почему на рынке выигрывают продукты, которые выполняют больше работ"

**Ключевая идея:** В конкурентной борьбе чаще выигрывают продукты, которые могут выполнять больше работ, чем их конкуренты — универсальные решения против узкоспециализированных.

**Примеры:**
- Смартфоны вытеснили навигаторы
- Смартфоны заменили MP3-плееры и фотоаппараты
- ChatGPT как более универсальная альтернатива поисковикам и репетиторам

**Инсайт:** Чем больше работ может выполнить один продукт, тем он более конкурентоспособен. Дополнительное преимущество — если не требуется переобучение продукту.

**Теги:** #jtbd@custdevlab #конкуренция@custdevlab

### 📋 Ручная настройка (альтернативный способ)

Если предпочитаете делать шаги вручную:

#### 1. Установка зависимостей

```bash
cd "/Users/pnevostruev/Downloads/Глоссаний метрик/CustDev Lab"
pip3 install -r requirements.txt
```

**Примечание:** На macOS используйте `pip3` вместо `pip`. Если не работает, попробуйте `python3 -m pip install telethon python-dotenv`

#### 2. Получение API ключей

1. Перейдите на https://my.telegram.org/apps
2. Войдите и создайте приложение
3. Скопируйте `api_id` и `api_hash`

#### 3. Настройка credentials

Создайте файл `.env` в директории проекта:

```
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
```

#### 4. Проверка доступа

```bash
python3 check_telegram_api.py
```

#### 5. Парсинг канала

```bash
python3 parse_channel.py
```

📖 **Подробная инструкция:** См. [SETUP.md](SETUP.md)

## 📋 Как использовать этот проект

### Для парсинга канала:
1. Настройте API ключи (см. [SETUP.md](SETUP.md))
2. Запустите `python check_telegram_api.py` для проверки
3. Запустите `python parse_channel.py` для парсинга
4. Посты сохранятся в `content/posts/`

### Для изучения CustDev:
1. Изучите материалы в `materials/frameworks/`
2. Прочитайте кейсы в `materials/cases/`
3. Проанализируйте посты в `content/posts/`

### Для анализа контента:
1. Просмотрите анализ тем в `analysis/topics/`
2. Изучите ключевые инсайты в `analysis/insights/`
3. Ознакомьтесь с метриками в `analysis/engagement/`

### Для создания материалов:
1. Следуйте структуре из `docs/structure.md`
2. Используйте принципы из `docs/guidelines.md`
3. Сохраняйте новые материалы в соответствующие папки

## 🔧 Технические детали

### Скрипты парсинга:
- **check_telegram_api.py** — проверка доступа к Telegram API
- **parse_channel.py** — основной скрипт для парсинга канала
- Использует библиотеку **telethon** для работы с Telegram API

### Форматы файлов:
- **Markdown (.md)** — для текстового контента и документации
- **JSON (.json)** — для структурированных данных (архивы постов)
- **CSV (.csv)** — для табличных данных
- **PDF (.pdf)** — для документов и презентаций

### Соглашения об именовании:
- Файлы постов: `post_XXX_краткое_описание.md`
- Архивы: `custdevlab_archive_YYYYMMDD_HHMMSS.json`
- Анализ: `analysis_тема_дата.md`
- Кейсы: `case_название.md`

### Зависимости:
- `telethon>=1.34.0` — для работы с Telegram API
- `python-dotenv>=1.0.0` — для загрузки переменных окружения
